Note on UD/PRE/chain-TCR: for these the usage lemmas are upper bounds valid for every WOTS
adversary `W` (the count depends on the digits `W` asks to sign: `preCount`, `tcrCount`), not
equalities; the caps now equal the best proved `W`-independent bound. Whether the bound is attained
by `bWotsS A` is not proved (not needed). The four class caps and the two FORS caps are attained
exactly (`bTcrArST_targets_eq_cap`; `Lazy.bOpenPreS_targets`).

## Generic transfer (`namespace Reduction.TightCaps`, any `SM_DT_TCR_Problem`)

```lean
@[reducible] def recap (prob) (n : ℕ) : SM_DT_TCR_Problem ι PkSeed Tweak M Y := { th := prob.th, thColl := prob.thColl, numTargets := n }
def retype (n : ℕ) (B : SM_DT_TCR_Adversary prob) : SM_DT_TCR_Adversary (recap prob n) := ⟨B.State, B.choose, B.forge⟩
theorem retype_choose : (retype n B).choose = B.choose := rfl      -- also retype_State, retype_forge
theorem run_mono : ∀ z ∈ support ((simulateQ (SM_DT_TCR_oracles prob pk) oa).run σ), σ.1.length ≤ z.2.1.length
theorem run_recap_eq (prob) (N) (hN : N ≤ prob.numTargets) (pk) (oa) (σ)
    (h : ∀ z ∈ support ((simulateQ (SM_DT_TCR_oracles prob pk) oa).run σ), z.2.1.length ≤ N) :
    (simulateQ (SM_DT_TCR_oracles (recap prob N) pk) oa).run σ = (simulateQ (SM_DT_TCR_oracles prob pk) oa).run σ
theorem experiment_retype_eq (N) (hN : N ≤ prob.numTargets) (B)
    (h : ∀ pk, ∀ z ∈ support ((simulateQ (SM_DT_TCR_oracles prob pk) B.choose).run ([], [])), z.2.1.length ≤ N) :
    SM_DT_TCR_Experiment (retype N B) = SM_DT_TCR_Experiment B
theorem advantage_retype_eq … : SM_DT_TCR_Advantage (retype N B) = SM_DT_TCR_Advantage B
```
The cap is not in the type of `choose`/`forge` (only `thColl` is), so re-typing copies the fields.
Result is an **equality of experiments** (hence of advantages), not just `≥`.

## Integration notes

- Add `import Reduction.TightCaps` and `import Reduction.TightCapsHeadline` to `Reduction.lean` (I did not
  edit the root). I wrote `.lake/build/lib/lean/Reduction/TightCaps{,Headline}.olean` by hand (no
  `.ilean`/`.trace`); a later `lake build` will simply rebuild them (≈7 s + 3 s).
- W1 (bytes) / uniform-seed corollaries: instantiate with `betaEufFinalTight` / `betaSufFinalTight` via
  `slhdsa_{euf,suf}_cma_final_tight'`; external: `external_bound_of_internal_bound betaEufFinalTight
  (slhdsa_euf_cma_final_tight' hS)`. If an existing corollary is stated for `beta*FinalSplit`, rewrite
  with `beta*FinalTight_eq hS A`.
- Hazard met: unifying a tight problem with its loose version makes Lean evaluate
  `arityTargets vp n =?= tcrTargets vp` (whnf timeout), and `rfl` between `(bTcrArST n A).choose` and
  `(bTcrArS n A).choose` unfolds the whole adversary. `TightCaps.lean` uses
  `attribute [local irreducible] arityTargets tcrTargets` (and `bTcrArS` for three lemmas). In new
  files, never state an equation whose two sides live over the two problems without that attribute;
  rewrite with `bTcrArST_advantage_eq` / `thashArityProblemT_numTargets` instead of `rfl`/`show`.
  Tactics must not see `x ∈ support (sparseTable …)`: use `exists_of_mem_support_map`.
- FINAL2 limitation 3 ("class-game caps are `tcrTargets`"; "cap of SM-TCR(F) on chains is
  `#inst·len·w`, used `≤ #inst·len·(w−1)`") is removed by the `_tight` theorems.
