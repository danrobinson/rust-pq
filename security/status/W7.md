## 2. UD hybrid (linear, single adversary — required form)

```lean
theorem wotsUD_telescope (hS : Structural vp prims) (pkSeedDist) (W : WotsGame.Adversary prims) :
    prTrue (WotsGame.hyb pkSeedDist (wotsInsts vp) 0 W) +
        ((vp.params.w - 2 : ℕ) : ℝ≥0∞) * SM_DT_UD_IdealSuccess (rUd pkSeedDist W) =
      ((vp.params.w - 2 : ℕ) : ℝ≥0∞) * SM_DT_UD_RealSuccess (rUd pkSeedDist W) +
        prTrue (WotsGame.hyb pkSeedDist (wotsInsts vp) (vp.params.w - 2) W)
```
Exact identity, every `w` (for `w ≤ 2` the factor is `0`). Adversary: the single SM-UD adversary
`rUd pkSeedDist W` (uniform hybrid index among `w−2` values) against `wotsUdProblem vp prims pkSeedDist`;
in the headline `W = Lazy.bWotsS A`. `Hyb₀` is the game before (charged to the forger's WOTS branch),
`Hyb_{w−2}` the game after (`≤ Adv^PRE(rPre W) + Adv^TCR(rTcr W)`, `stepWotsFinal`).
Per-index forms (need `3 ≤ w`):
```lean
theorem udRealSuccess_rUd_sum  (hS) pkSeedDist W (hw : 3 ≤ vp.params.w) :
    ((w - 2 : ℕ) : ℝ≥0∞) * SM_DT_UD_RealSuccess  (rUd pkSeedDist W) = ∑ k ∈ Finset.range (w - 2), prTrue (WotsGame.hyb pkSeedDist (wotsInsts vp) k W)
```

(`hidx .real k = k`, `hidx .ideal k = k + 1`.) `WotsUD.udFixed` is the SM-UD *experiment* of `rUd W` with


## 6. Sanity

- No `-` (truncated subtraction) occurs in any linear statement; the only occurrence in the file is in
  `dsprAdvantage_eq_sub`/`dsprSuccess_le`, which tie to the existing advantage.
- All eight named probabilities are `≤ 1` (lemmas in the legend); `linearIdealSide ≠ ⊤` (`linearIdealSide_ne_top`), so
  the ideal side is finite and cancellable — this is what `boundFinalTight_of_linear` uses.
- Dropping any left term gives a weaker true statement; the full strength (all four ideal terms on the
  left) is what implies the absolute-value headline.

## Notes for the ideal-model team

- Averaging over a table `g`: every term on both sides is `𝒟[experiment] {true}` of an explicit
  `ProbComp Bool` (or `(w−2)·`/`3·` such), so the inequality averages termwise.
- The PRF/PRF_msg part is exact (equalities in §1); if only an upper bound on
  `E_g[prfRealPr − prfIdealPr]` is available, use the hop equalities directly instead of the headline.
- `prfIdealPr B` and `msgIdealPr B` do not depend on `PRF`/`PRF_msg` but do depend on `Thash`/`H_msg`
  through the distinguisher `B` (it simulates the scheme).
