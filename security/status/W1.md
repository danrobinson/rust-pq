## 1. Generic transfer (`namespace Reduction.Coded`)

```lean
structure View (alg : SignatureAlg ProbComp M PK SK S) (balg : SignatureAlg ProbComp M PKb SKb Sb) where
  encPk : PK → PKb;  encSk : SK → SKb;  encS : S → Sb;  decS : Sb → Option S
  keygen_eq : balg.keygen = (fun ks => (encPk ks.1, encSk ks.2)) <$> alg.keygen
  sign_eq   : ∀ pk sk m, balg.sign (encPk pk) (encSk sk) m = encS <$> alg.sign pk sk m
  verify_eq : ∀ pk m sb, balg.verify (encPk pk) m sb =
                match decS sb with | some s => alg.verify pk m s | none => pure false
  canonical : ∀ sb s, decS sb = some s → encS s = sb
def reduce  (v) (fallback : S) (adv : UnforgeableAdversary balg) : UnforgeableAdversary alg where
  main pk := readForgery v fallback <$> simulateQ (signingImpl v) (adv.main (v.encPk pk))
def reduceS …                                       -- same program, StrongUnforgeableAdversary
theorem unforgeableAdvantage_le        v fb adv : Adv_euf(adv) ≤ Adv_euf(reduce v fb adv)
theorem strongUnforgeableAdvantage_le  v fb adv : Adv_suf(adv) ≤ Adv_suf(reduceS v fb adv)
theorem reduce_queryBound / reduceS_queryBound : IsQueryBoundP (adv.main (v.encPk pk)) (·.isRight) qs →
    IsQueryBoundP ((reduce v fb adv).main pk) (·.isRight) qs
```
`signingImpl`: sampling queries forwarded; a signing query `m` = exactly one typed query `m`, answer
encoded. `readForgery (m, sb) = (m, (decS sb).getD fallback)`. Only `canonical` (decode succeeds only on
canonical encodings) is used for SUF; injectivity of the encoding is not needed for this direction.
Key lemma `runWithSigningOracle_signingImpl` (byte run = typed run of the simulation with the log encoded).

## 2. Byte-level cores and schemes (generic in `vp`, `prims`, `codec : CoreWireCodec vp.params prims.core`)

```lean
def byteKeygen (skSeed skPrf pkSeed) : List Byte × List Byte        -- (encodePublicKey pk, encodeSecretKey sk)
def byteSign (m sk : List Byte) (addrnd : prims.Y) : List Byte      -- decodeSecretKey; ok k ↦ encodeSignature (signInternal m k addrnd); error ↦ []
def byteVerify (m sig pk : List Byte) : Bool                        -- decodeSignature, decodePublicKey; both ok ↦ verifyInternal; else false
def byteSignPure (m ctx sk) (addrnd) : Option (List Byte)           -- (signPureWithRandomizer …).toOption.map encodeSignature; bad sk ↦ none
def byteVerifyPure (m sig ctx pk) : Bool
noncomputable def bytesAlg vp prims codec optRand pkSeedDist : SignatureAlg ProbComp (List Byte) (List Byte) (List Byte) (List Byte)
noncomputable def pureBytesAlg … : SignatureAlg ProbComp (List Byte × List Byte) (List Byte) (List Byte) (Option (List Byte))
```
Argument orders mirror the Rust functions. `bytesAlg`: keygen = sample (`pkSeedDist`, uniform, uniform),
`pure (byteKeygen …)`; sign `pk sk m` = parse `pk` (only to feed `optRand`), `addrnd ← optRand k`,
`pure (byteSign m sk addrnd)`, and `pure []` if `pk` does not parse; verify = `pure (byteVerify m sig pk)`.
`pureBytesAlg`: sign `(M, ctx)` = `none` without sampling if `|ctx| > 255` (FIPS Alg. 22 line 1; equals
`byteSignPure` there, `byteSignPure_tooLong`), else as above with `byteSignPure`; verify `(some raw)` =
`byteVerifyPure`, `none` rejected.

**Secret-key type: bytes** (`List Byte`, FIPS `SK.seed‖SK.prf‖PK.seed‖PK.root`, via VCVio's
`encodeSecretKey`/`decodeSecretKey`) — cheap, and it makes the Rust `sk` argument literally the scheme's.
Signature type of the external scheme: `Option (List Byte)`, the Rust return type of `slh_sign`
(`rust_sign`: `r.map bytes = (…).toOption.map sigBytes`).
Malformed inputs (not reachable in the games or from Rust): wrong-length pk/sig ⇒ verify rejects
(`byteVerify_of_pk_length_ne`, `byteVerify_of_sig_length_ne`); wrong-length sk ⇒ `[]` / `none`
(`byteSign_of_sk_length_ne`); `[]` never accepted (`byteVerify_nil`, needs `signatureBytes ≠ 0`).

Views: `bytesView : Coded.View (internalAlg …) (bytesAlg …)`, `pureBytesView : Coded.View (externalAlg …) (pureBytesAlg …)`
(`encodePureSig = toOption.map encodeSignature`; `decodePureSig none = none`, `some raw ↦ (decodeSignature raw).toOption.map .ok`).

**Remaining gap scheme-in-the-game vs Rust** (stated in the doc comment of `bytes_standard_model_security`):
(i) sampling: scheme draws `PK.seed ← pkSeedDist`, `SK.seed`, `SK.prf` uniform, `opt_rand ← optRand pk`; Rust takes them as arguments;
(ii) `Room m.length 152` (internal) / `409` (external) on the Rust side;
(iii) Rust keys are `[u8; 32]`, `[u8; 64]`; the scheme takes any byte strings and rejects / returns `[]` or `none`
 on wrong lengths (lemmas above); every 32/64-byte string parses, no secret-key well-formedness check;
(iv) representations: Aeneas `U8` lists ↔ `List UInt8` by `wire` (bijection); seeds/`addrnd` 16-byte arrays ↔ nodes
 (`Vector UInt8 16`) by `node`; `byteKeygen` returns `(pk, sk)`, Rust `(sk, pk)`;
(v) `sign` in the scheme parses the public key to evaluate `optRand`; Rust signing has no pk argument;
 external: `none` for over-long context is returned before sampling;
(vi) unchanged: advantages unbounded, no running time, single key, compiler/Aeneas/side channels.

Note: a direct `rfl` between `rust_verify_internal`'s `match` and `byteVerify` failed (different matcher
constants); proved by case analysis instead — statements unaffected.
