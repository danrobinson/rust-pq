# C2 — strong unforgeability (SUF-CMA) in the standard model

(Note added by the W6 documentation sweep) "Headline" below is the phase-1 theorem `Reduction.slhdsa_suf_cma` (old PRF game `skPrf`, which is false at SHA2-128s; eager-table adversaries; eight terms). The current SUF-CMA theorems are `slhdsa_suf_cma_final_split` and `slhdsa_pure_suf_cma_final_split` (`Reduction/HeadlineSplit.lean`; `skPrfC`, table-free adversaries, twelve terms, internal and external interface).

**Verdict: proved, unconditionally, with no extra assumption.** `Reduction.slhdsa_suf_cma` bounds
the SUF-CMA advantage of every strong forger against `internalAlg vp prims optRand pkSeedDist` by
the *same* `bound` as `slhdsa_euf_cma`: same eight games, same six adversaries after the PRF hops
(`bItsr`, `bOpenPre`, `bTcr`, `rUd/rPre/rTcr (bWots ·)`), and two PRF distinguishers that differ
from `bPrf`/`bPrfMsg` only in the output bit. No `sorry`, `axiom`, `native_decide`, `bv_decide`;
no named hypothesis left; `#print axioms` = `[propext, Classical.choice, Quot.sound]` for every
theorem below.

## Assessment (task 1)

A strong forgery `(M, σ*)`: valid, not a returned pair. In `G2` the oracle's answer on `(M, R)`
is the reference signature `idealSign tbl M pk R`, a function of `(M, R)`.

**(i) `R*` differs from every randomizer used for `M`.** Already covered by the EUF machinery
once freshness is taken per `(M, R)` pair, with no change of game:

* VCVio's ITSR win condition is `(R*, x*) ∉ targets ∧ all indices covered`, i.e. pair-based;
  `wins_of_itsr_pair` / `br_itsr` prove the ITSR branch from pair-freshness alone.
* The other three branches never used freshness: `br_open` (OpenPRE, no validity or freshness),
  `br_coll` (SM-TCR(Thash), no condition at all), `br_wots` (WOTS game, validity only).
* The existing step lemmas (`stepSplit`, `stepITSR`, …) are *stated* for `g2Class`, which
  contains the message-freshness check, so they could not be cited; the branch lemmas above are
  re-proofs in pair-fresh form against the same adversaries. Result: `g2Fresh_le`.

**(ii) Same `R`, different body.** `sameRandomizer_collision` (deterministic, no probability):
two different signatures with the same randomizer that both verify for `M` under `pk` either

* WOTS+-sign different messages with the same recovered chain ends at some layer
  (`wotsLayer?` is `some`) — the existing WOTS event, charged to
  `(w−2)·SM-UD(F) + SM-PRE(F) + SM-TCR(F)` through `bWots` exactly as in EUF; or
* make two verification hash calls at the same tweak, different inputs, same output. Sub-cases
  proved: `F` on a revealed FORS secret (`suf_fors_collision`), an `H` node of a FORS or XMSS
  authentication path (`suf_climb_collision`), `T_k`, `F` inside a WOTS+ chain when the signed
  message agrees but a signature value differs (`suf_chain_collision`, `suf_wots_collision`),
  `T_len`.

Are those positions declared targets? **Yes, already.** `bTcr` plays the single SM-TCR game on
the variable-arity `Thash` (`tcrProblem`) and declares *every* hash call of the honest key
structure as a target (`honestCalls`, cap `tcrTargets`); `verifyCalls_idealSign_subset` says all
verification calls of any reference signature are among them. That includes `F` at every FORS
leaf on its secret value and `F` at every WOTS+ chain position — the two positions the task
suspected were missing. So the collision is a win of the existing `bTcr` with its existing
target set (`evColl_of_coll`, `br_coll`). The PRE / OpenPRE games are not used for this case.

Consequences:

* **Extra named assumption terms: none.** No new game, no new target, no change of any cap.
* This rests on FINAL limitation 3 (one cross-arity SM-TCR(Thash) game whose targets are all
  hash calls of the structure). In a paper-style decomposition with per-function TCR games
  (HK22, the EasyCrypt artefact) the same argument needs SM-TCR(F) targets at the *revealed* FORS
  leaves and at *all* WOTS+ chain positions including those at or below the revealed value; I
  have not checked whether the target sets of those per-function games as written in HK22/EC
  include them. That question does not arise for the theorem proved here.
* **Hedged vs deterministic signing does not matter**: the theorem holds for every `optRand`.
  Signing `M` again with a different `opt_rand` gives a second randomizer for `M`; both pairs are
  in the transcript and the case split is per pair. Signing with the same `(opt_rand, M)` reuses
  the cached `R` (lazy random *function*) and returns the identical signature.
* Relation to VCVio's ROM lane (`SufResidual.lean`: `itsrFresh_or_sameRandomizer`): same
  dichotomy (pair-fresh, or a logged signature with the same randomizer that differs in the FORS
  or hypertree half). Here the second branch is closed in the standard model by SM-TCR.

## Exact statements

`A := S.toUnforgeableAdversary` is the same program (`main := S.main`).
`WinCheck vp prims := PublicKeyCore prims.core → List Byte × SignatureCore → SigLog vp prims → Bool`.

Headline (`Reduction/Suf.lean`):

```lean
theorem slhdsa_suf_cma (hS : Structural vp prims)
    (S : SignatureAlg.StrongUnforgeableAdversary (realAlg vp prims optRand pkSeedDist)) :
    SignatureAlg.strongUnforgeableAdvantage ProbCompRuntime.probComp S ≤
      bound pkSeedDist (bPrfW sufCheck S.toUnforgeableAdversary)
        (bPrfMsgW sufCheck S.toUnforgeableAdversary)
        (bItsr S.toUnforgeableAdversary) (bOpenPre S.toUnforgeableAdversary)
        (bTcr S.toUnforgeableAdversary)
        (rUd pkSeedDist (bWots S.toUnforgeableAdversary))
        (rPre pkSeedDist (bWots S.toUnforgeableAdversary))
        (rTcr pkSeedDist (bWots S.toUnforgeableAdversary))
```

`strongUnforgeableAdvantage` is VCVio's (`SignatureAlg.lean`: valid pair not in the log of
returned pairs). `bound` is `Reduction.bound` (`Steps.lean`) — PRF + PRF_msg + ITSR + OpenPRE +
TCR(Thash) + (w−2)·UD + PRE + TCR(F). `Structural` is the same non-cryptographic hypothesis.

Corollaries and modular forms (same file unless noted):

```lean
theorem slhdsa_sha2_128s_suf_cma optRand pkSeedDist S : … ≤ bound …     -- SufInstance128s.lean, no hypothesis

theorem slhdsa_suf_cma_resources hS S qs
    (hA : ∀ pk, IsQueryBoundP (S.main pk) (fun i => i.isRight = true) qs) :
    (the bound) ∧
    IsQueryBoundP (bPrfW sufCheck A) (·.isRight = true) (2^h'·len + qs·signReads vp) ∧
    IsQueryBoundP (bPrfMsgW sufCheck A) (·.isRight = true) qs ∧
    IsQueryBoundP (bItsr A).main (·.isRight = true) qs

theorem suf_le_prf_add_g2 hS S :                                        -- hops only
    strongUnforgeableAdvantage S ≤ (skPrf vp prims).prfAdvantage (bPrfW sufCheck A) +
      (msgPrf vp prims).prfAdvantage (bPrfMsgW sufCheck A) + prTrue (g2W sufCheck A)

theorem expW_le_prf_add_g2 hS (w : WinCheck vp prims) A :               -- hops, any final check
    prTrue (expW realAlg w A) ≤ PRF(bPrfW w A) + PRF_msg(bPrfMsgW w A) + prTrue (g2W w A)

theorem g2W_le_g2Bound hS w (hw : ∀ pk f log, w pk f log = true → sufCheck pk f log = true) A :
    prTrue (g2W w A) ≤ g2Bound A        -- g2Bound = the six non-PRF terms at bItsr … rTcr

theorem slhdsa_sameMessage_le hS S :
    sameMessageStrongUnforgeableAdvantage S ≤ bound pkSeedDist (bPrfW sameCheck A)
      (bPrfMsgW sameCheck A) (bItsr A) (bOpenPre A) (bTcr A) (rUd …) (rPre …) (rTcr …)

theorem slhdsa_suf_cma_of_euf hS (β : Forger … → ℝ≥0∞)
    (hβ : ∀ B, unforgeableAdvantage ProbCompRuntime.probComp B ≤ β B) S :
    strongUnforgeableAdvantage S ≤ β A + (the bound of slhdsa_sameMessage_le)
```

`slhdsa_suf_cma_of_euf` is the "`SUF ≤ EUF(toEuf S) + residual`" form asked for; `toEuf` is
VCVio's `toUnforgeableAdversary`. It is looser than the headline when `β` is itself `bound` (the
six `G2` terms occur twice), and the residual needs all six terms, not only TCR and WOTS: a new
randomizer on an already signed message is a new `H_msg` input and can land in the ITSR or
OpenPRE branch.

## Adversaries (BRIEF2 obligations)

* `bPrfW w A` / `bPrfMsgW w A` are `bPrf A` / `bPrfMsg A` with the harness `runForgerSig`
  (records returned `(message, signature)` pairs instead of messages) and output bit
  `w pk forgery log`. Black-box, straight-line, run the forger once. Same oracle queries as the
  EUF versions (`bPrfW_queryBound_exact`, `bPrfMsgW_queryBound`).
* `sufCheck` = `!signingLogContains log M σ && verifyInternal …`, with decidable equality of
  signatures built from `DecidableEq prims.Y` (`sigDecEq`, via the extensionality lemmas) — not
  the classical instance. `strongAdvantage_eq_expW` identifies it with VCVio's experiment (which
  uses the classical instance).
* Choice check (temporary script, definition bodies only, never proofs): `sufCheck`, `sameCheck`,
  `sigDecEq`, `runForgerSig`, `bPrfW`, `bPrfMsgW` reach no `Classical.*` constant; as a control
  the same script flags `sufWin` (a proof-side predicate that does use classical `decide`).
* The other six adversaries are the existing ones, unchanged; their caps and "no query refused"
  lemmas apply verbatim.
* **No new game**: the PRF games are the existing `skPrf`/`msgPrf` experiments, the SUF
  experiment is VCVio's, `expW`/`g2W` are intermediate experiments not appearing in the headline.
  Hence no new non-vacuity lemma. Not proved: that the SUF advantage can be positive.

## What package A must re-instantiate

The headline is against the v1 games and eager-table adversaries. For a v2 statement:

1. Six non-PRF terms: nothing to redo. `g2W_le_g2Bound` gives `Pr[g2W sufCheck A] ≤ g2Bound A`
   at `bItsr A`, …; A's equalities (e.g. `bItsrL` has the advantage of `bItsr`) rewrite the terms.
2. `bPrfMsgW` samples the eager `sampleTable` like `bPrfMsg`. A lazy variant needs A's
   lazy = eager lemma applied to `runForgerSig` instead of `runForger` (same shape; state is the
   pair log).
3. PRF game restricted to canonical addresses: `stepPRFW` is stated for `skPrf vp prims`. The
   proof goes through one program identity (`rest_sim` in `SufHopPrf.lean`) and
   `queriesIn_bRest` (all queries canonical), so the port should mirror whatever A does for
   `bPrf`.
4. Entry points that do not depend on any of this: `expW_le_prf_add_g2` (takes the hops as they
   are), `g2W_le_g2Bound`, `slhdsa_suf_cma_of_euf` (takes any `∀ B, Adv B ≤ β B`).

## Limitations

* All limitations of FINAL.md except "EUF-CMA, not SUF-CMA" still apply (unbounded right-hand
  advantages, no running-time claim, eager table, single key, internal algorithms only).
* The PRF distinguishers of the SUF and EUF theorems are different programs, so the two bounds
  are not term-by-term comparable in their first two summands.
* `SufHopPrf.lean` / `SufHopMsg.lean` restate about 450 lines of private lemmas of `PRFHop.lean` /
  `PRFMsgHop.lean` (query counting, naturality, cache-of-transcript). A later clean-up could make
  the originals generic in the final check and derive the EUF hops from `stepPRFW`/`stepPRFmsgW`.
