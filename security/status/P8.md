## Proof structure (for dependants / reuse)

Generic, reusable by P7 (WOTS-UD) since `rUd` is also a `simChoose` instance:

- `WotsFinal.nested_run` — for `S : QueryImpl spec₀ (StateT H (OracleComp spec₁))` run inside
  `O : QueryImpl spec₁ (StateT Σ ProbComp)` versus a game `G : QueryImpl spec₀ (StateT H ProbComp)`:
  a per-query hypothesis (`run =ᵈ F <$> mx`, game step `=ᵈ (F ·).1 <$> mx`, invariant preserved)
  gives `Prod.fst <$> nested run =ᵈ game run` plus the invariant on the support.
- `WotsFinal.ofFnM_run_sample` / `ofFnM_run_det` — state-passing evaluation of
  `simulateQ O (Vector.ofFnM f)` when each component consumes one uniform sample / is
  deterministic; the first produces `$ᵗ (Vector β n)` on the nose.
- `WotsFinal.outer`, `simImpl`, `outer_lift`, `sim_step` — the per-query hypothesis of
  `nested_run` for any `simChoose` instance against `WotsGame.oracles k`, reduced to two facts
  about the reduction: `hcoll` (collection call at a non-reserved key returns `Thash`) and `hsign`
  (the `startVal` loop is distributed as `hybSig k` of a uniform vector; the `chainHash` loop
  returns `wotsPkFromSigTops`; invariant re-established).
- `WotsFinal.stepKey_inj`, `reservedKey_stepKey`, `hist_length_lt` — distinct chain-step tweaks
  and the instance count bound.

Specific: `PreInv` / `TcrInv` (history ↔ SM-game state), `pre_hcoll`, `pre_hsign`, `tcr_hcoll`,
`tcr_hsign`, `pre_bound`, `tcr_bound`, and the assembly through `gameTriple`
(`Pr[win] ≤ Pr[PreGood ∨ TcrGood] ≤ Pr[PreGood] + Pr[TcrGood]`).
