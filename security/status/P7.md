## Statement-change requests to frozen files

None. The frozen `StepWotsUD` is correct as stated; checked by proving against it:

- Hybrid index: ONE adversary `rUd` that samples `k ← $ᵗ Fin (w-3+1)` (i.e. `k ∈ {0..w-3}`,
  `w-2` values when `w ≥ 3`), not a sum over `w-2` adversaries. `experiment_eq` shows the SM-UD
  experiment is the uniform mixture over `k` of the fixed-index experiments, and `udFixed_eq`
  shows the fixed-index experiment is exactly (equal in distribution) `hyb k` in the real world
  and `hyb (k+1)` in the ideal world. Telescoping gives
  `Pr[hyb 0] + (w-2)·Pr[ideal] = (w-2)·Pr[real] + Pr[hyb (w-2)]`, hence the coefficient `(w-2)`
  on `SM_DT_UD_Advantage (rUd W)` (= `boolDist`, i.e. `|real − ideal|`; only `real ≤ ideal + adv`
  is used). The coefficient is exact, not slack.
- `w < 3`: `w - 2 = 0` in ℕ, so both hybrids coincide and the step is `x ≤ x + 0`; no hypothesis
  on `w` is needed in `stepWotsUD` (the two averaged lemmas keep `hw : 3 ≤ w`, needed for
  `w-3+1 = w-2`).
- Query legality (no refusals) is proven: each chain issues at most one challenge (cap
  `wotsChainTargets = #inst·len` suffices), challenge tweaks (step `k` of chains with digit
  `> k+1`) are never spent on the collection oracle and vice versa (`UdInv`), using
  `Structural.keyInj` + `bounds` through `WotsFinal.stepKey_inj`. `hS.byteLaws` is not used.
- `wotsUdProblem` has `inputGen = outputGen = $ᵗ Y`, `emb = id`: matches the hybrids on the nose.
