## Definitions

Generic (`namespace Reduction.Guarded`, `alg : SignatureAlg ProbComp M PK SK S`,
`enc : E → Except ε M`):

- `scheme alg enc : SignatureAlg ProbComp E PK SK (Except ε S)` — keygen of `alg`;
  `sign pk sk e` = `pure (.error x)` if `enc e = .error x`, else `.ok <$> alg.sign pk sk m`;
  `verify pk e s` = `alg.verify pk m σ` if `enc e = .ok m`, `s = .ok σ`, else `pure false`.
- `signingImpl enc` — forwards sampling queries; signing query `e`: error locally, or one query
  `m` to own oracle.
- `reduce alg enc fallback adv : UnforgeableAdversary alg` —
  `main pk := readForgery enc fallback <$> simulateQ (signingImpl enc) (adv.main pk)`;
  `readForgery` returns `(m, σ)` when `enc e = .ok m` and the signature is `.ok σ`, else the fixed
  pair `fallback : M × S`.

SLH-DSA (`namespace Reduction`):

- `pureEncode (mc : List Byte × List Byte) := External.encodePureMessage mc.2 mc.1`
  (message first, context second).
- `externalAlg vp prims optRand pkSeedDist : SignatureAlg ProbComp (List Byte × List Byte)
  (PublicKeyCore prims.core) (SecretKeyCore prims.core)
  (Except External.Error (GeneralScheme.SignatureCore vp prims.core))
  := Guarded.scheme (internalAlg vp prims optRand pkSeedDist) pureEncode`.
  Signature type `Except External.Error Sig` = return type of `signPureWithRandomizer`, so `sign`
  is literally the external function; an error value is never accepted by `verify`.
- `ExtForger vp prims optRand pkSeedDist := UnforgeableAdversary (externalAlg …)`.
- `constSig (y : prims.Y)` — all-`y` signature; `toInternal A :=
  Guarded.reduce (internalAlg …) pureEncode ([], constSig default) A` (needs `[Inhabited prims.Y]`,
  already a standing instance of the headline theorem; `Reduction/Instance128s.lean` provides it
  for 128s).

```lean
theorem encodePureMessage_ok_iff (context message enc : List Byte) :
    External.encodePureMessage context message = .ok enc ↔
      context.length ≤ 255 ∧ enc = [0, UInt8.ofNat context.length] ++ context ++ message

theorem encodePureMessage_injective (context context' message message' enc : List Byte)
    (h : External.encodePureMessage context message = .ok enc)
    (h' : External.encodePureMessage context' message' = .ok enc) :
    context = context' ∧ message = message'

theorem Guarded.unforgeableAdvantage_le (alg) (enc)
    (hinj : ∀ e e' m, enc e = .ok m → enc e' = .ok m → e = e') (fallback : M × S)
    (adv : SignatureAlg.UnforgeableAdversary (scheme alg enc)) :
    SignatureAlg.unforgeableAdvantage ProbCompRuntime.probComp adv ≤
      SignatureAlg.unforgeableAdvantage ProbCompRuntime.probComp (reduce alg enc fallback adv)

    (h : IsQueryBoundP (adv.main pk) (fun i => i.isRight = true) qs) :
    IsQueryBoundP ((reduce alg enc fallback adv).main pk) (fun i => i.isRight = true) qs

theorem externalAlg_sign (pk sk) (message context : List Byte) (h : context.length ≤ 255) :
    (externalAlg vp prims optRand pkSeedDist).sign pk sk (message, context) =
      (do let addrnd ← optRand pk
          pure (External.signPureWithRandomizer vp prims message context sk addrnd))
theorem externalAlg_sign_tooLong … (h : 255 < context.length) :
    (externalAlg …).sign pk sk (message, context) = pure (.error (.contextTooLong context.length)) ∧
      ∀ addrnd, External.signPureWithRandomizer vp prims message context sk addrnd =
        .error (.contextTooLong context.length)
theorem externalAlg_verify_ok (pk) (message context) (σ) :
    (externalAlg …).verify pk (message, context) (.ok σ) =
      pure (External.verifyPure vp prims message σ context pk)
theorem externalAlg_verify_error (pk) (mc) (x) : (externalAlg …).verify pk mc (.error x) = pure false

-- non-vacuity (via External.verifyPure_signPureWithRandomizer)
theorem externalAlg_correct (message context : List Byte) (hc : context.length ≤ 255)
    (skSeed) (skPrf) (pkSeed) (addrnd : prims.Y) :

        (GeneralScheme.keygenInternal vp prims skSeed skPrf pkSeed).1 (message, context) (.ok σ) =
          pure true
```

## Notes / limitations

- Inequality, not equality: when the external forger's output is malformed (over-long context or
  an error value as signature) `toInternal` must still output an internal pair and outputs the
  fixed `([], constSig default)`, which could in principle verify. Equality would need an
  internal adversary type that may abort; not needed for the bound.
- The reduction is tight (coefficient 1, zero additive loss), straight-line, runs `A` once, no
  sampling of its own, signing queries ≤ those of `A` (over-long-context queries cost none).
- The generic part is stated for `ProbComp` schemes (`spec = unifSpec`), which is all the
  standard-model development uses. VCVio's `SignatureAlg.Wire` pattern was followed
  (`runWithSigningOracle_signingImpl`, `fresh_of_fresh`), but `Wire.scheme` itself is not usable:
  it needs a total encoding (fixed context) and is stated for SUF adversaries in the ROM runtime.
- Covered: pure mode, arbitrary contexts chosen per query by the adversary (the message space of
  the game is `(message, context)`). Not covered: pre-hash (Alg. 23/25) and mixed pure/pre-hash
  use of one key; SUF-CMA; multi-key; byte-level (wire) forgeries — the game is on typed
  signatures/keys, parsing is only in the functional Rust link; seed/`opt_rand` sampling
  (caller's obligation); the eight hash-game advantages are unproven assumptions.
  (Note added by the W6 documentation sweep) of this list, now covered: SUF-CMA of the external interface (`Reduction/ExternalSuf.lean`, `slhdsa_pure_suf_cma_final_split`) and byte-level forgeries (`Reduction/Bytes.lean`, `status/W1.md`); the current bound has twelve advantages (`Reduction/HeadlineSplit.lean`), and "headline theorem" in this file means the phase-1 `slhdsa_euf_cma`.
- Integration for packages A/B: for a new internal theorem `∀ B, Adv B ≤ β B` use
  `external_bound_of_internal_bound β hβ A`; if the new theorem has a query-bound hypothesis on
  `B`, discharge it at `toInternal A` with `toInternal_queryBound`.
